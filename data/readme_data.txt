Data Source

The stock data used in this project comes from Yahoo Finance and is downloaded using the yfinance Python package.

Assets Used

The project uses historical daily stock data for the following assets:

- SPY
- AAPL
- MSFT
- GOOG
- AMZN

Data Description

The raw data contains daily OHLCV information:

- Open price
- High price
- Low price
- Close price
- Adjusted close price
- Trading volume

The project generates technical indicators from the raw stock data, such as daily return, moving averages, volatility, volume ratio, and price-based features.

How to Obtain the Data

If the CSV data file is not included in the submitted folder, the data can be regenerated by running the download script:

python scripts/download_data.py

The downloaded data should be saved inside the data folder.

Expected Data Location

The main data file should be placed at:

data/stock_data.csv

Notes

The data is used for educational purposes in the DSCI-441 course project. The project focuses on classical machine learning model comparison, time-series evaluation, anomaly detection, and interpretability.
